# أبو عزت TV | AboEzzat TV

مشروع مستقل لتوسيع تجربة **AboEzzat Receiver** إلى شاشات LG وSamsung واللابتوبات، مع الحفاظ على التوافق مع **AboEzzat Cast** قدر الإمكان.

> **الحالة الحالية:** مرحلة التخطيط والتحقق من البروتوكول. لم يتم نقل كود Android أو إصدار تطبيق قابل للتثبيت بعد.

## الهدف

إنشاء مستقبل متعدد المنصات يقدم نفس تجربة ومميزات AboEzzat Receiver، مع واجهة مناسبة للتلفزيون بالريموت وللابتوب بالماوس والكيبورد.

## المنصات المستهدفة

- **LG Smart TV:** تطبيق webOS.
- **Samsung Smart TV:** تطبيق Tizen.
- **Windows / macOS / Linux laptops:** تطبيق ويب/PWA أو حزمة سطح مكتب حسب الحاجة.

كل منصة قد تحتاج حزمة وطبقة تشغيل خاصة بها؛ لا نفترض أن APK Android واحد سيعمل على جميع الأجهزة.

## المميزات المطلوب الحفاظ عليها

- استقبال المحتوى المرسل من AboEzzat Cast.
- تشغيل روابط الفيديو المباشرة وملفات الصور.
- دعم HLS (.m3u8) والصيغ التي يدعمها مشغل المنصة.
- قائمة تشغيل عند الحاجة، والتحكم في التشغيل والتوقف والتنقل.
- واجهة تلفزيون واضحة ومتوافقة مع الريموت.
- واجهة مناسبة للماوس والكيبورد على اللابتوب.
- عرض حالة الاتصال ومعلومات الجهاز.
- إعدادات وسجل تشغيل حيث تسمح المنصة.
- معالجة أخطاء التشغيل وإظهار رسالة مفهومة بدل الادعاء بنجاح التشغيل.

## المرجع الأساسي

المستودع المرجعي: [AboEzzat-Receiver](https://github.com/mohamedezzat19/AboEzzat-Receiver)

الملفات الأساسية التي تمت مراجعتها:
- `MainActivity.java`: واجهة Android، استقبال الطلبات، تشغيل الوسائط، الصور والمتصفح.
- `ReceiverServerService.java`: خدمة استقبال HTTP واكتشاف الأجهزة.
- `AndroidManifest.xml` و`app/build.gradle`: صلاحيات Android واعتماديات Media3/ExoPlayer.

## نقطة التوافق المهمة مع AboEzzat Cast

الريسيفر Android الحالي يستقبل HTTP على المنفذ **8081** ويستخدم UDP multicast على **37020** لاكتشاف الأجهزة. تطبيقات webOS وTizen والويب ليست Android، ولا يمكن افتراض أنها ستستطيع فتح نفس خادم TCP/UDP من داخل واجهة الويب.

لذلك يجب اختبار واختيار طريقة اتصال مناسبة لكل منصة قبل الادعاء بالتوافق الكامل. الخيارات التي ستُدرس:
1. الحفاظ على بروتوكول Cast الحالي حيث تسمح المنصة.
2. إضافة طريقة اتصال بديلة متوافقة مع TV/desktop، مع تعديل AboEzzat Cast عند الحاجة وبشكل منفصل.
3. استخدام اكتشاف/اقتران واضح وآمن بدل الاعتماد على اكتشاف الشبكة وحده.

**لن يتم تغيير AboEzzat Cast أو AboEzzat Receiver الأصليين ضمن هذا المستودع.** أي تعديل مطلوب عليهما سيُعرض ويُختبر بشكل مستقل.

## خطة التنفيذ

1. توثيق بروتوكول الإرسال والاستقبال الحالي من AboEzzat Cast وReceiver.
2. تحديد طبقة اتصال مشتركة وبدائل المنصات.
3. إنشاء واجهة مشتركة للمشغل والتحكم.
4. بناء نموذج أولي للابتوب أولًا لتجربة البروتوكول والواجهة.
5. إعداد تطبيق webOS واختباره على محاكي LG ثم جهاز حقيقي.
6. إعداد تطبيق Tizen واختباره على محاكي Samsung ثم جهاز حقيقي.
7. اختبار الفيديو والصور والروابط والريموت وحالات انقطاع الشبكة.
8. توثيق خطوات البناء والتثبيت لكل منصة.

## تنبيهات

- دعم صيغ الفيديو يختلف حسب موديل التلفزيون وإصدار النظام.
- لا نعتبر أي منصة مدعومة نهائيًا إلا بعد اختبار فعلي.
- لا نضع مفاتيح أو كلمات مرور أو شهادات توقيع داخل المستودع.
- لا نعد بميزة غير منفذة أو غير مختبرة.
